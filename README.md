# ExamSprint full practice build

Files required in the GitHub Pages root:
- `index.html` — app interface and practice flow
- `questions.json` — original questions, options, correct answers, explanations
- `manifest.json` — install metadata
- `sw.js` — offline caching

## Publish / update
Upload all four files to the repository root, replacing files with the same names. Keep GitHub Pages on `main` and `/(root)`. Wait for deployment and refresh the site.

## Current content
- 200 generated, arithmetic-checked Simplification questions with answer explanations and distractor options
- Additional original practice questions across Quantitative Aptitude, Reasoning, English, Banking & Financial Awareness, Computer Aptitude, General Awareness, and Professional Subjects
- Exam directory includes major IBPS, SBI, RBI, NABARD, regulatory, public-sector bank, insurance, and IIBF categories

These are original practice questions, not copied official previous-year papers. Exam patterns and recruitment eligibility change; consult the official recruitment notice linked inside the app. Before wide public launch, manually review question wording and answer explanations, especially current-affairs content which is not included as live news.
